About this report
  • COMPLIANT = at most 2 valid minor upgrade target(s) for the current version; NON-COMPLIANT = 3 or more; UNKNOWN = lookup failed or current version not returned (deprecated).
  • Counted are only the valid minor upgrade targets RDS returns for the server's current version (describe-db-engine-versions --engine-version <current>, ValidUpgradeTarget with IsMajorVersionUpgrade=false). Latest minor per major = highest valid target seen (or the current version when up to date).
  • Regions: queried directly, no probe. Empty regions are only counted; tables list regions with databases or an AWS error.
  • Pending maint. = maintenance actions AWS has scheduled or offered for this server that haven't been applied yet (cluster rows include their member instances' actions); click the badge to expand, hover for IST dates.
  • Global databases (Aurora): membership from describe-global-clusters (one call per account). Overall status = the worst member; region status mismatch = members on the same version but with a different status (valid targets differ per region). Automatic minor version upgrade does not apply to global database members.
  • Read-only: nothing was changed.
